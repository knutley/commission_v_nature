# Retrieval terms and tagging dictionaries.

# RETRIEVAL. An article is retrieved if its metadata (title, abstract,
# keywords) matches:   ([eu] AND [climate]) OR [standalone]
# The query is deliberately neutral about linkages, so the corpus isn't
# biased toward the themes you then go on to measure.
#
# TAGGING. [tag:NAME] sections are NOT used for retrieval. After download,
# each article's title + abstract is scanned and the number of hits is stored
# in a tag_NAME column: a rough first-pass indicator of each linkage, to
# check against your hand-coding, not a substitute for it.
#
# Syntax: one term per line; multi-word terms are matched as phrases;
# "net zero" also matches "net-zero"; a trailing * matches word endings
# (tagging only). Short all-caps acronyms (EU, ETS) are case-sensitive.
